#### Hi, I'm Kwabena.

I'm a Python and backend developer in Kalmar, Sweden, looking for a remote role.
Each project below has a test suite, runs CI on every pull request, and says in its
README what it does not do.

- **[askpdf](https://github.com/kwagyei/askpdf)**: ask questions about a folder of PDFs.
  Every answer cites a page, and the quote is checked word for word against that page.
  Runs locally with Ollama, and its retrieval and answers are measured on a frozen test split.
- **[entropass](https://github.com/kwagyei/entropass)**: a password and passphrase generator
  that reports exact entropy in bits. [On PyPI](https://pypi.org/project/entropass/), with no
  runtime dependencies.
- **[ecommerce-shopfront](https://github.com/kwagyei/ecommerce-shopfront)**: a Django store
  with Stripe test-mode checkout and a webhook that fulfils each order once, even under
  retries and races. [Live demo](https://shopfront-da2o.onrender.com) (free hosting, so the
  first load can take a minute).
- **[stock-scanner](https://github.com/kwagyei/stock-scanner)**: paper-trades attention
  signals on Stockholm small caps against a pre-registered PASS/FAIL test.
- **[dagens-menu](https://github.com/kwagyei/dagens-menu)**: a bilingual restaurant site
  template on Cloudflare Workers, where one codebase serves each restaurant from its own content.
